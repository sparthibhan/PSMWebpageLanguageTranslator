PSMWebpageLanguageTranslator is an open-source Google Chrome extension that translates the full content of the active webpage into a user-selected language to facilitate reading and comprehension. The extension automatically detects the page's language and translates visible text into the preferred language within seconds.

Features: Automatic language detection; full-page translation; user-selectable target language; lightweight and privacy-conscious operation.
Installation: Load the extension in Chrome via chrome://extensions using "Load unpacked" for the extension directory, or install from the Chrome Web Store if a packaged release is provided.
Usage: Click the extension icon and select the desired language; the extension will translate the page content in-place.
